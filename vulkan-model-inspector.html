3D Model Inspector (Vulkan)

Model Inspector (Vulkan)

This project is a real-time 3D model inspector built with the Vulkan API. The application provides an interactive environment for inspecting 3D models, materials, and lighting while showcasing a range of modern real-time rendering techniques.

Bindless Resources

Textures are managed through a bindless-style resource system. A single descriptor set contains an array of textures, with materials storing indices that are used directly in the shader to access their corresponding resources. This approach simplifies resource binding and allows a large number of textures to be accessed without requiring individual descriptor bindings for each material texture.

Physically Based Rendering

The renderer implements physically based rendering (PBR) using the Metallic-Roughness workflow. Material properties such as base color, metallic, and roughness are combined with the lighting environment to produce physically plausible surface responses.

Image-Based Lighting

Image-Based Lighting (IBL) is used to provide realistic environment illumination. The environment map is convolved and prefiltered into multiple mipmap levels, with each level representing a different degree of roughness. During rendering, the material's roughness is used to select the appropriate mip level, allowing surfaces with different roughness values to sample the environment with the corresponding level of specular blur.

A BRDF integration LUT is also generated to account for the view-dependent portion of the specular BRDF, completing the split-sum approximation used for real-time specular IBL.

Directional Shadows - PCSS

Directional lighting is combined with a shadow mapping system to produce dynamic shadows. To achieve more realistic soft shadows, the renderer implements Percentage-Closer Soft Shadows (PCSS), dynamically estimating the penumbra based on the distance between the occluder and the receiver.
