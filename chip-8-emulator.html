CHIP-8 Emulator

CHIP-8 Emulator

This project consists of the implementation of a complete CHIP-8 emulator and disassembler in C++. The goal was to accurately reproduce the behavior of the original CHIP-8 virtual machine, including graphics, input handling, timers, sound generation and instruction execution.

  • Disassembler: Loads .ch8 ROM files, decodes 16-bit big-endian opcodes and generates their corresponding CHIP-8 assembly representation.
  • SDL2 Host Layer: Provides a monochrome 64x32 display, keyboard input mapping for all 16 CHIP-8 keys and support for sound playback through the system speaker.
  • CPU Emulation: Implements the full CHIP-8 instruction set, including memory management, registers, stack operations, timers, jumps, arithmetic operations and input instructions.
  • Graphics System: Supports sprite rendering using XOR drawing, collision detection through the VF register and screen wrapping behavior matching the original hardware.
  • Testing: Verified using the Timendus CHIP-8 Test Suite to ensure correct opcode behavior and compatibility with existing ROMs.
  • Playable Games: The final emulator successfully runs multiple CHIP-8 games with functional graphics, sound, controls and gameplay logic.

This project provided practical experience in hardware emulation, instruction decoding, low-level memory management, timing systems and graphics programming while recreating the behavior of a classic virtual machine from the late 1970s.

CHIP-8 Specifications

  • Memory: 4KB RAM and a stack supporting nested subroutine calls.
  • Registers: Program Counter (PC), Index Register (I), and 16 general-purpose registers (V0-VF).
  • Display: 64×32 monochrome framebuffer.
  • Timers: Delay Timer (DT) and Sound Timer (ST), both running at 60Hz.
  • Input: 16-key hexadecimal keypad mapped to the keyboard.

Instruction Set

The emulator implements the complete CHIP-8 instruction set, including flow control, arithmetic operations, memory access, timers, sprite rendering, keyboard input and random number generation.

All instructions are 16-bit opcodes decoded at runtime and executed according to the original CHIP-8 specification. Unknown instructions are reported as invalid opcodes during emulation.

Validation & Testing

The emulator was validated using the Timendus CHIP-8 Test Suite , which verifies instruction decoding, arithmetic behavior, graphics rendering, memory operations, timers and keyboard input handling. The available test ROMs were used throughout development to ensure compatibility with the official CHIP-8 specification and expected emulator behavior.

Additional compatibility testing was performed using ROMs from the CHIP-8 Archive, a CC0 collection of CHIP-8 programs and games. These ROMs were used to verify correct execution of real applications, graphics rendering, sound generation, input handling and overall gameplay behavior.
